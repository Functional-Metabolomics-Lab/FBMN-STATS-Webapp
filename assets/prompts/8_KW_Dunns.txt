**Page Summary: Kruskal-Wallis & Dunn's Post-hoc Test**

**Functionality:**
This page performs the Kruskal-Wallis (KW) test, a non-parametric alternative to one-way ANOVA, used to determine if there are statistically significant differences between three or more independent groups. It is ideal for non-normal or heteroscedastic data. If the KW test reveals significance, the user can proceed with Dunn's post-hoc test for a selected pair of groups. Dunn's test is only run on KW-significant features and uses the pooled ranking of all groups included in the KW test; the result for the selected pair is reported.

**Parameters:**
- **Attribute:** A categorical column from the metadata selected by the user to define the sample groups (e.g., Treatment).
- **Groups for KW:** A multiselect option requiring at least three groups from the chosen attribute to be included in the global Kruskal-Wallis test.
- **Dunn's Comparison:** Two specific groups (A = first selected, B = second selected) from the KW groups.
- **P-value Correction:** The globally selected method (Benjamini-Hochberg FDR by default). For KW it is applied across metabolites; for Dunn's test it is applied across all pairwise group comparisons within each feature (as FSA::dunnTest(method = 'bh') in the protocol).

**Results:**
- **Kruskal-Wallis Results:**
    - *Feature Significance Plot:* Scatter plot of ln(H) vs. -log10(corrected p) for all features.
    - *Results Table:* Dataframe listing the H-statistic, raw p-value, corrected p-value, and boolean significance for each feature across the multiple groups.
    - *Single Metabolite Boxplots:* Visual distribution of intensities for a selected metabolite across all the groups included in the KW test.
- **Dunn's Post-hoc Results:**
    - *Volcano Plot (protocol):* Dunn's Z statistic (A − B) vs. -log10(adjusted p) for the pairwise comparison.
    - *Fold-change Volcano Plot:* log2(mean B / mean A) vs. -log10(adjusted p); only shown for non-negative, unscaled intensities.
    - *Results Table:* Dataframe with Z statistic, mean-rank difference, unadjusted and adjusted p-values, and significance for the specific group contrast.
