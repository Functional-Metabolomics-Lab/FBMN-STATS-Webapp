**Page Summary: Friedman Test**

**Functionality:**
This page performs the Friedman test, a non-parametric alternative to repeated-measures one-way ANOVA, used to determine if there are statistically significant differences among three or more paired/matched groups. It is ideal for non-normal or heteroscedastic data from repeated-measures or matched designs. No post-hoc test is run on this page; pairwise follow-up comparisons can be done on the Wilcoxon Signed-Rank page.

**When to use:**
Use this test when you have three or more paired or matched groups (e.g., multiple time points on the same subjects, before/during/after treatment) and normality cannot be assumed. The metadata must contain a subject/pairing column identifying the same subject across conditions. Subjects that are not measured in every selected group are excluded.

**Parameters:**
- **Attribute:** A categorical column from the metadata selected by the user to define the sample groups (e.g., Timepoint, Condition).
- **Groups for Friedman:** A multiselect option requiring at least three groups from the chosen attribute to be included in the omnibus Friedman test.
- **Subject / pairing column:** Metadata column that defines the blocks (subjects) of the Friedman test.
- **P-value Correction:** The globally selected method for multiple comparison adjustment (e.g., Benjamini-Hochberg FDR, Bonferroni, or none).

**Results:**
- **Friedman Results:**
    - *Feature Significance Plot:* Scatter plot of ln(Chi²) vs. -log10(corrected p) for all features.
    - *Results Table:* Dataframe listing the chi-squared statistic, raw p-value, corrected p-value, boolean significance and number of complete subjects for each feature.
    - *Single Metabolite Boxplots:* Visual distribution of intensities for a selected metabolite across all groups included in the test.

**Next potential pages:**
- Wilcoxon Signed-Rank: pairwise follow-up comparisons between two of the paired groups.
- Repeated Measures ANOVA: parametric alternative if normality holds.
