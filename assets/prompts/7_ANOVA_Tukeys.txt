**Page Summary: One-way ANOVA & Tukey's Post-hoc Test**

**Functionality:**
This page conducts a One-way ANOVA (Analysis of Variance) to assess if there are statistically significant differences among the means of three or more independent groups. This is a parametric test assuming normality and variance homogeneity. If the global ANOVA detects significant differences, the user can then run Tukey's HSD (Honestly Significant Difference) post-hoc test for a selected pair of groups. Tukey's test is only run on ANOVA-significant features, and it is fit on all groups included in the ANOVA (pooled error variance, adjusted for all pairwise comparisons); the result for the selected pair is reported.

**Parameters:**
- **Attribute:** A categorical column from the metadata selected by the user to define the sample groups (e.g., Treatment).
- **Groups for ANOVA:** A multiselect option requiring at least three groups from the attribute to be included in the global ANOVA test.
- **Tukey's Comparison:** Two specific groups (A = first selected, B = second selected) from the ANOVA groups.
- **P-value Correction:** The globally selected method for multiple comparison adjustment across metabolites (e.g., Benjamini-Hochberg FDR, Bonferroni, or none), applied to both the ANOVA and the Tukey results.

**Results:**
- **ANOVA Results:**
    - *Feature Significance Plot:* Scatter plot of ln(F) vs. -log10(corrected p) for all features (as in the protocol).
    - *Results Table:* Dataframe listing the F-statistic, raw p-value, corrected p-value, and boolean significance for each feature.
    - *Single Metabolite Boxplots:* Visual distribution of intensities for a selected metabolite across all the groups included in the ANOVA.
- **Tukey's Post-hoc Results:**
    - *Volcano Plot (protocol):* Difference of group means (mean A − mean B) vs. -log10(corrected Tukey p).
    - *Fold-change Volcano Plot:* log2(mean B / mean A) vs. -log10(corrected p); only shown for non-negative, unscaled intensities.
    - *Results Table:* Dataframe detailing the difference in means, group means, p-values (Tukey's and corrected), and significance for the specific group contrast.
